# DAF / CacheBlend 服务器复现指南

> 本文档写给**在 GPU 服务器上执行复现的人或 AI agent**。
> 按顺序执行即可。所有命令默认在 Linux（Ubuntu 20.04/22.04）上以普通用户运行。
>
> 仓库内容说明：本仓库是 CacheBlend 原型（vllm 0.4.1 魔改版，位于 `vllm_blend/`），
> 已实现 DAF 算法（由 `cache_fuse_metadata["daf"]` 开关控制，详见 `docs/daf1.0.md`）。
> 实验记录见 `docs/daf_experiment_10samples.md`。

---

## 0. 硬件与环境要求

| 项目 | 要求 |
|---|---|
| GPU | NVIDIA，显存 ≥8GB（≥16GB 可用非量化模型，更贴近论文） |
| 驱动 | `nvidia-smi` 可用，右上角 CUDA Version ≥ 12.1 |
| 硬盘 | ≥30GB 空闲 |
| 内存 | ≥16GB（编译 vllm 需要） |
| 系统 | Ubuntu 20.04 / 22.04 推荐 |

**先确认显卡型号**（决定第 3 步的 `TORCH_CUDA_ARCH_LIST`）：

```bash
nvidia-smi --query-gpu=name,memory.total --format=csv
python3 -c "import torch; print(torch.cuda.get_device_capability())" 2>/dev/null || echo "torch 未装，装好后再查"
```

| 显卡 | TORCH_CUDA_ARCH_LIST |
|---|---|
| V100 | `"7.0"` |
| A100 | `"8.0"` |
| RTX 3090/4090/4060 等 | `"8.6"` / `"8.9"`（4090/4060 用 8.9） |
| H100 | `"9.0"` |

## 1. 安装 Miniconda 和编译工具

```bash
# Miniconda（已装可跳过）
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p ~/miniconda3
~/miniconda3/bin/conda init bash
source ~/.bashrc

# 创建环境（Python 必须 3.10，与开发环境一致）
conda create -n cacheblend python=3.10 -y
conda activate cacheblend

# CUDA 12.1 工具链（nvcc、头文件、静态库，编译 vllm 需要）
conda install -c nvidia cuda-toolkit=12.1 -y

# 编译工具
sudo apt update && sudo apt install -y cmake ninja-build build-essential
# 无 sudo 权限时改用：
# conda install -c conda-forge cmake ninja gxx_linux-64 -y
```

## 2. 安装 Python 依赖（版本必须严格对齐）

```bash
conda activate cacheblend

# PyTorch 2.2.1 + cu121（不要装更新的版本）
pip install torch==2.2.1 --index-url https://download.pytorch.org/whl/cu121

# 关键依赖：xformers 必须 0.0.25，transformers 必须 4.41.2
#（transformers 新版会导致 vllm 0.4.1 崩溃）
pip install xformers==0.0.25 transformers==4.41.2 rouge_score

# 国内服务器可用清华镜像加速：上面每条命令末尾加 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> ⚠️ **绝对不要安装 flash-attn**。vllm 检测到它会自动切换到 FlashAttention 后端，
> 而 DAF/CacheBlend 的全部改动都在 xformers 后端（`vllm_blend/vllm/attention/backends/xformers.py`），
> 装了 flash-attn 会导致 DAF **静默失效**（不报错，但代码根本不执行）。

## 3. 编译安装 vllm_blend（关键步骤）

```bash
cd ~/CacheBlend/vllm_blend   # 换成你 clone 的实际路径

export CUDA_HOME=$HOME/miniconda3/envs/cacheblend
export MAX_JOBS=$(nproc)              # 编译并行度 = CPU 核数
export TORCH_CUDA_ARCH_LIST="8.0"     # ← 按第 0 步的表修改！
export TMPDIR=$HOME/.tmp && mkdir -p $TMPDIR   # /tmp 太小的话防止编译爆盘

pip install -r requirements-cuda.txt
pip install -e . --no-build-isolation
```

编译需要 10~30 分钟。验证：

```bash
python -c "import vllm; print('vllm', vllm.__version__)"
# 期望输出：vllm 0.4.1
```

## 4. 下载模型（二选一）

```bash
# 国内服务器先设置镜像（推荐写入 ~/.bashrc）
export HF_ENDPOINT=https://hf-mirror.com

# 选项 A：显存 ≥16GB，用官方非量化版（约 15GB，贴近论文实验配置）
huggingface-cli download mistralai/Mistral-7B-Instruct-v0.2

# 选项 B：显存 8GB 级，用 AWQ 4bit 量化版（约 4GB，与开发机一致）
huggingface-cli download TheBloke/Mistral-7B-Instruct-v0.2-AWQ
```

## 5. 按模型调整 example/blend.py

打开 `example/blend.py`，只改开头的模型加载部分：

**选项 A（非量化模型）**：

```python
llm = LLM(model="mistralai/Mistral-7B-Instruct-v0.2",
          gpu_memory_utilization=0.85,
          max_model_len=4096,        # 显存大可以加大，如 32768，用于长上下文实验
          enforce_eager=True)
tokenizer = AutoTokenizer.from_pretrained("mistralai/Mistral-7B-Instruct-v0.2")
```

**选项 B（AWQ 量化版）**：保持现状不用改（仓库里默认就是这套）。

## 6. 运行实验

```bash
cd ~/CacheBlend   # 仓库根目录（blend.py 依赖 inputs/ 相对路径）

# 原版 CacheBlend 对照（10 个样本）
DAF=0 python example/blend.py 2>&1 | tee run_cb.log

# DAF（10 个样本）
DAF=1 python example/blend.py 2>&1 | tee run_daf.log
```

每个样本输出 4 行关键结果：`Cached generation`（融合答案）、`TTFT with cache`、
`Normal generation`（全量重算答案）、`TTFT with full prefill`。

## 7. 验证成功的标准

- 10 个样本全部跑完，无 AssertionError、无 NaN 报错
- 参考基线（开发机 RTX 4060 上的结果，见 `docs/daf_experiment_10samples.md`）：
  - CacheBlend 与全量一致约 8/10，DAF 约 6/10（小样本，仅作功能参考）
  - 两种融合方法的 TTFT 都应明显低于全量重算
- 生成内容读起来通顺、与问题相关（样本 1 正确答案：Carnegie Mellon University）

## 常见问题（踩坑记录）

| 症状 | 原因 | 解决 |
|---|---|---|
| `pip install vllm` 报 Long Path / 文件名过长 | 你在 Windows 上直接装了 | 本项目必须在 Linux/WSL2 里装 |
| transformers 报错 `Cache` 相关 | transformers 版本太新 | `pip install transformers==4.41.2` |
| 编译报 nvcc / 静态库缺失 | CUDA toolkit 不完整 | 确认 `conda install -c nvidia cuda-toolkit=12.1` 成功 |
| DAF 好像没生效 | 装了 flash-attn，后端被切走 | `pip uninstall flash-attn`，日志应显示 `Using XFormers backend` |
| 连不上 huggingface.co | 国内网络 | `export HF_ENDPOINT=https://hf-mirror.com` |
| `No available memory for the cache blocks` | 显存被其他进程占了 | `nvidia-smi` 查看并清掉占用进程，或调低 `gpu_memory_utilization` |

## 实验噪声控制（测速度时必读）

- 不要在有桌面环境的机器上测 TTFT（桌面程序会抢 GPU）；纯服务器无此问题
- 可选：锁频 `sudo nvidia-smi -lgc <频率>`（如 A100: `-lgc 1410`），测完 `-rgc` 恢复
- 同一配置跑 3 遍取中位数
- DAF 的优势区间在长上下文（论文：6k 持平、30k 拉开、136k 差距大），
  短上下文下 DAF 略慢于 CacheBlend 是**预期现象**，不是 bug
